# Cooperative_rendezvous
Aim to design a fully distributed control method for the cooperative rendezvous between unmanned vehicles.

## Paper
"Distributed Control Method for Vehicle Cooperative Rendezvous", Journal of Guidance, Control, and Dynamics, DOI: 10.2514/1.G008445. [Link](https://arc.aiaa.org/doi/abs/10.2514/1.G008445)

## Result
The distributed control framework, based on rendezvous parameter optimization, generates the control commands to achieve cooperative rendezvous.
